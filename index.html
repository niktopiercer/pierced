Architettura & Conformità Legale

Informativa sulla Privacy & Architettura Offline-First

Pierced è un'applicazione desktop stand-alone. Non possiede server cloud proprietari né raccoglie dati telemetrici. Tutti i dati anagrafici dei clienti, le note cliniche, i consensi informati e le registrazioni contabili risiedono esclusivamente sul disco locale del computer dell'utente (formato SQLite protetto).

Google Calendar API & Limited Use Disclosure

L'applicazione richiede unicamente l'autorizzazione di sola lettura https://www.googleapis.com/auth/calendar.readonly per mostrare gli impegni all'interno dell'agenda dello studio. Pierced non richiede e non possiede permessi di scrittura, modifica o cancellazione dei calendari Google.

I token di autenticazione OAuth 2.0 vengono conservati in modo cifrato unicamente nel portachiavi nativo del sistema operativo (macOS Keychain o Windows Credential Manager). Nessun dato viene trasferito, sincronizzato su server terzi o venduto a terze parti.

L'accesso può essere revocato in qualunque momento direttamente dall'app (Impostazioni > Disconnetti Google) oppure dalla gestione sicurezza del proprio Account Google.

Clausola di conformità Google API:
L'uso delle informazioni ricevute dalle API di Google rispetta la Google API Services User Data Policy, inclusi i requisiti di Limited Use.

"Pierced's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements."
